The Popover API

只要在按鈕加上 popovertarget="id"，再給目標元素 popover 屬性， 瀏覽器就會幫你接好開關、ESC 鍵關閉、點空白處 light-dismiss、焦點管理 — 一行 JavaScript 都不用。

02
invoker · commandfor / command

The Dialog + Command

<dialog> 處理 modal 焦點陷阱、ESC 關閉、backdrop。新的 commandfor + command 屬性讓「按鈕開 dialog」也變成純 HTML — 連 showModal() 都不用呼叫。下方兩種寫法並列：經典 JS 與新版宣告式。

Classic JS showModal()

仍然要寫一行 JS，但 <dialog> 已內建焦點與 ESC。

command attribute Chrome 135+

HTML 純宣告 — command="show-modal"。

Confirm flow danger zone

同樣機制，套在「危險動作」的確認框。

dialog.html invoker commands 
// New, declarative — no JavaScript
<button commandfor="my-dialog" command="show-modal">Open</button>

<dialog id="my-dialog">
  <p>Content here</p>
  <button commandfor="my-dialog" command="close">Close</button>
</dialog>

// Classic — fallback for older browsers
<button onclick="myDialog.showModal()">Open</button>
Why it matters

Userland libraries validate a pattern. The web platform absorbs it — with accessibility, focus management and dismissal behaviours baked in. Less code. Fewer bugs. Same UX.
