# ---

**專案重構與 Tree-Shaking 拯救計畫 (Save State)**

## **📝 專案背景與現況**

本專案為大型 **Vue 單頁應用程式 (SPA)**，採用**多品牌 (白牌) 架構**。專案透過 Vite 進行打包，並高度依賴環境變數與 resolve.alias 來動態切換不同品牌的設定與路由。

**目前最大技術債：Tree-Shaking 機制近乎失效。**

由於歷史包袱（如集中匯出檔 Barrel Files、頂層呼叫副作用 Top-level side effects），導致模組依賴關係糾纏。單一組件的引入往往會引發「拔出蘿蔔帶出泥」的連鎖反應，將數十個不相干的檔案（甚至其他品牌的路由頁面）全部打包進來，嚴重影響載入效能與維護性。

## ---

**🎯 核心目標**

建立一套自動化的「依賴分析與測試管線」，從最底層的組件開始，由下而上（Bottom-up）逐層清除副作用，最終恢復專案健康的 Tree-Shaking 機制，並補齊單元測試防護網。

## ---

**🏗️ 戰略藍圖：雙視角分析架構**

為了克服 Vite alias 解析方向（由上而下）與我們重構方向（由下而上）的矛盾，我們將開發一套基於 Node.js 與 Vite Programmatic API 的自定義分析腳本，分為兩種運行模式：

### **1\. 宏觀模式 (Macro Mode) \- 「全知地圖」**

* **作法**：以 main.js 為入口，注入特定品牌的環境變數啟動 Vite 打包。攔截 Rollup 的 generateBundle 階段。  
* **目的**：  
  * 取得該品牌**最真實的存活模組圖 (Module Graph)**。  
  * 找出現階段沒有任何外部依賴的「最末端樹葉節點 (Leaf Components)」。  
  * 未來可用於反查孤兒檔案 (Orphan Files) 並進行大掃除。

### **2\. 微觀模式 (Micro Mode) \- 「毒性檢測儀」**

* **作法**：以單一組件（如 Button.vue）作為虛擬入口進行獨立打包。  
* **目的**：  
  * 檢測該組件的依賴純潔度。若預期產出 1 個檔案卻產出 50 個，即代表該組件踩中 Tree-Shaking 地雷。  
  * 作為修復副作用（如拔除 Barrel File 引用、加入 /\* @\_\_PURE\_\_ \*/ 註解）後的驗證工具。

## ---

**🔄 標準工作流 (重構與測試雙軌並行)**

這是一套結合 **「副作用清除」** 與 **「單元測試」** 的拓撲排序修復流程：

1. **鎖定目標**：透過宏觀腳本，找出底層的「樹葉節點」。  
2. **微觀檢測與修復**：將樹葉節點丟入微觀腳本。若產出異常龐大，修正其 import 來源或架構，直到打包結果乾淨為止。  
3. **撰寫單元測試**：確認組件依賴乾淨後，使用 **Vitest \+ Vue Test Utils** 撰寫測試。  
   * *單純 UI*：直接 Mock Props 與 Emit。  
   * *狀態依賴*：使用 @pinia/testing 建立隔離的假 Store。  
   * *API 依賴*：使用 **MSW (Mock Service Worker)** 或 vi.mock 攔截網路請求，確保測試環境的絕對隔離。  
4. **驗收與晉級**：測試通過後將該節點標記為健康（綠燈），接著往上一層依賴它的父組件推進，重複步驟 1\~4。

## ---

**🛠️ 關鍵技術與避坑指南 (Knowledge Base)**

* **Barrel Files 的危害**：避免使用 export \* from './index.js' 這種集中匯出寫法，這會強迫打包工具解析整條依賴鍊，極易引發 Tree-Shaking 失效。應改為精確路徑引入。  
* **魔法註解拯救頂層呼叫**：對於 export const i18n \= createI18n(...) 這類無惡意副作用的頂層宣告，加上 /\* @\_\_PURE\_\_ \*/ 註解可讓 Rollup 放心將其搖除。  
* **強制照妖鏡**：在偵錯階段，可暫時於 package.json 加入 "sideEffects": false 或在 Rollup 設定中微調 moduleSideEffects，強迫清除死碼，藉此比對出是哪裡牽扯了髒依賴。  
* **動態引入 (Dynamic Import)**：() \=\> import('./views/About.vue') 無法修復壞掉的 Tree-Shaking，但能做到「損害控管」，將冗餘程式碼隔離在特定的 Chunk 中，保護首頁載入速度。
