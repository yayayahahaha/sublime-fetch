# 創建/修改一個白牌的時候可以用的工具

> 大部分還是需要手動就是了

## 環境

| Application | Version |
| ----------- | ------- |
| Nodejs      | 18^     |

## 怎麼用

```bash
# 安裝 pacakges
pnpm install

node index.js
```

接著照著跳出來的提示處理想做的事情即可
